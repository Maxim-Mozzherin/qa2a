# 🚀 QA2A — Складской учёт и интеграция с iiko RMS

Enterprise-бэкенд сервиса складского учета, инвентаризации, заявок на закупку и интеграции с **iiko RMS** для заведений общественного питания (HoReCa) на базе **Telegram Mini App**.

---

## 🏗 Архитектура и технологии

* **Язык разработки:** Go 1.22+
* **СУБД:** PostgreSQL 14+ (пул `sqlx`, миграции)
* **Клиентский интерфейс:** Telegram WebApp (Mini App), Telegram Bot API
* **Шифрование и безопасность:** 
  * AES-256-GCM с PBKDF2 (100 000 итераций) для защиты мастер-паролей iiko
  * Криптографическая подпись токенов авторизации (HMAC-SHA256)
  * Версионирование сессий (`token_version`) и мгновенная инвалидация доступа
  * Защита от SSRF и DNS-Rebinding (`pkg/netutil`) на уровне сокетов
  * Защита от DoS (ограничение размера тела запросов через `http.MaxBytesReader`)
  * Защита от перебора и брутфорса (`pkg/ratelimit`)
* **Интеграция с iiko RMS:**
  * Авторизация через Session Key
  * Синхронизация номенклатуры, складов и категорий
  * Снятие остатков через OLAP iiko
  * Ежедневная регламентная выгрузка списаний и актов приготовления (06:30 YEKT)
  * Экспорт актов инвентаризации (XML v1 / JSON v2)

## 📂 Структура репозитория

```text
├── cmd/
│   ├── api/            # Точка входа HTTP API бэкенда
│   └── loadtest/       # Утилита нагрузочного тестирования API
├── docs/               # Полная Enterprise-документация (части 1-6)
├── internal/
│   ├── auth/           # Валидация Telegram WebApp initData
│   ├── bot/            # Telegram-бот администрирования, мониторинга и бэкапов
│   ├── config/         # Конфигурация приложения из .env
│   ├── crypto/         # Симметричное шифрование AES-256-GCM и PBKDF2
│   ├── database/       # Инициализация пула соединений PostgreSQL
│   ├── handlers/       # HTTP-контроллеры API (REST)
│   ├── middleware/     # Аутентификация, RBAC, контекст пользователя/поставщика
│   ├── models/         # Доменные сущности и структуры данных
│   ├── repository/     # Доступ к данным и SQL-запросы к PostgreSQL
│   └── service/        # Бизнес-логика, интеграция с iiko, регламентный планировщик
├── pkg/
│   ├── netutil/        # Защищенный HTTP-транспорт с защитой от SSRF
│   └── ratelimit/      # In-memory Rate Limiter с ограничением по IP и действиям
└── web/                # Шаблоны HTML и статика фронтенда
```

## 🛠 Запуск и сборка

### Локальный запуск
```bash
# 1. Установка переменных окружения
cp .env.example .env

# 2. Сборка бинарного файла
go build -o qa2a ./cmd/api

# 3. Запуск сервиса
./qa2a
```
