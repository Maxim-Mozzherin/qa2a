# 🌟 QA2A Site — Витрина бизнеса (qa2a.ru)

Современный представительский сайт-витрина для сервиса **QA2A** (Quick Analytics to Accounting): независимый аудит цен сырья, сверка накладных iiko RMS и автоматизация учета для ресторанного бизнеса (HoReCa).

---

## ✨ Особенности дизайна и архитектуры
* **Стилистика:** Премиальный светлый B2B SaaS (сочетание эстетики *Zoho Mail* и *Google Antigravity*):
  * Мягкие пастельные световые сферы и аурный фон (без кричащего неона).
  * Стеклянные панели с эффектом матового стекла (`backdrop-filter: blur(14px)`).
  * Карточки проблем и решений с 3D-переворотом на 180° (*Flip Cards* в духе Zoho).
  * Интерактивный дашборд-превью в первом экране:
    * Таб 1: Сверка накладных и выявление переплат по позициям сырья.
    * Таб 2: Аналитика фудкоста и динамика потерь.
    * Таб 3: Telegram Mini App для инвентаризации кухни и бара.
  * Интерактивный калькулятор переплат (ползунок оборота закупки + выбор количества заведений + разбивка экономии по группам товаров).
  * Интерактивная таблица «Живой срез рынка» с фильтрами по цехам (рыба, молочка, мясной цех, бакалея).
  * Регламент запуска за 3 простых шага.
  * Матрица преимуществ «С QA2A vs Без QA2A».
  * Интерактивный аккордеон FAQ.
  * Модальное окно экспресс-заявки с праздничным салютом конфетти и мгновенным переходом в Telegram.

---

## 🚀 Локальный запуск
Страница является полностью автономной, не требует тяжелых локальных сборщиков и мгновенно открывается в любом браузере:

```bash
# Вариант 1: Открыть напрямую в браузере
start index.html

# Вариант 2: Запуск через легкий веб-сервер Node.js
npx serve .
```

## 🔗 Интеграция с бэкендом
В проекте `qa2a-reboot` данный шаблон подключен напрямую в `web/templates/landing.html` и отдается по корневому пути `/` через Go-роутер.
